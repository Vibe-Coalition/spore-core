Meet SPORE

An AI agent with a persistent knowledge graph as its identity — not static prompts, not stateless chat. Every conversation adds nodes, edges, and reflections. Over time, it forms a self.

This setup takes a minute. You'll pick a look, create an account, and connect at least one model provider.

System Prompt Budgets

Token caps applied when assembling the agent's system prompt. Sections that exceed their cap are silently truncated from the END — leave defaults unless the plan-mode verification logs report missing markers (docker logs ... | grep '[plan-mode]'). Changes apply on the next turn — no restart needed.
Carries project context, sandbox rules, plan-mode block (PHASE 1-5 + QUESTIONS protocol + tooling-question list + RULES). Bump this when you've added prompt content and the agent stops following late-block instructions.
Hard cap on total system prompt size in tokens. The DROP_ORDER list (gaps → anti → selfknowledge → plugin → feed → tooling → runtime → reflections → derived → episodes) trims sections from least-important first when the total exceeds this.

Reset Graph

Destructive. Wipes everything in this agent's graph DB — every node, aspect, attribute, edge, episode, gap, reflection — and re-applies the seeded reference nodes from /app/reference-nodes.sql + every migrate-ref-*.sql. Use this when you want to start the agent's memory from scratch (dev testing, changed your mind about training, suspected corruption, etc.). The DB file is backed up to <path>.pre-reset.<ts> before the wipe so the action is recoverable.
Type RESET in the box below to enable the button. Effect is immediate, no restart needed — the live graph handle is mutated in place.
